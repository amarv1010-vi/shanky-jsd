JSD PHOTOS — WHERE EACH FOLDER FROM YOUR MAC GOES
==================================================

Your website reads THIS "gallery" folder automatically. Copy your photos from
your "jsd_photos" folders into the matching folder below, then upload.

YOUR MAC FOLDER                 -->  PUT INTO THIS FOLDER (here)
--------------------------------------------------------------------
Featured photos (featured 1-6) -->  featured/
Evergreen St Rochedale (E1-E9) -->  evergreen/
Kenmore (K1-K9)                -->  kenmore/
Sunnydale Project (S1-S10)     -->  sunnydale/
Ongoing projects (WhatsApp...) -->  active/
AI Images (AI 1-6)             -->  build-types/
Video (Video1.mp4)             -->  video/

Just drag the images in. Keep the file names as they are (E1.jpg, featured 1.jpg,
AI 1.jpg, WhatsApp Image 1.jpeg, Video1.mp4, etc.) — the site reads the number in
each name to order them. You do NOT need to rename or crop anything.

WHERE EACH APPEARS ON THE SITE
--------------------------------------------------------------------
  featured/     -> Home page "Featured Projects" (6 images, zoom on hover)
  evergreen/    -> Projects page, filter "Evergreen St, Rochedale"
  kenmore/      -> Projects page, filter "Kenmore"
  sunnydale/    -> Projects page, filter "Sunnydale"
  active/       -> Projects page, filter "Active Projects"
  build-types/  -> Projects page, the 6 build-type boxes (AI 1..6 map to:
                   AI1 High-Set Rochedale, AI2 Low-Set Springwood,
                   AI3 Split-Level Eight Mile Plains, AI4 Commercial Underwood,
                   AI5 High-Set Calamvale, AI6 Commercial Ipswich)
  video/        -> Home page main video (auto-plays, muted, loops)

HOW TO UPLOAD (one time, ~5 min)
--------------------------------------------------------------------
1. Fill the folders above with your photos + the video.
2. Select this whole "gallery" folder -> right-click -> Compress -> gallery.zip
3. cPanel -> File Manager -> open  public_html/uploads/
4. Upload gallery.zip  ->  right-click  ->  Extract  (overwrite when asked)
5. Refresh the website. Home shows your featured photos + video; Projects shows
   your project photos with the new filters + the 6 AI build-type boxes.

SIZES: no cropping needed. Photos auto-fit a clean 3:2 frame. The video should
be 16:9 (yours is) and it sits in a cinematic 16:9 frame automatically.

(You can delete this file from the server afterwards.)
